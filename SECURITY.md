# Security Policy

Marak is currently pre-1.0. The actively maintained line is the current development branch and current prerelease compiler; no long-term support or response-time SLA is promised yet.

Please report security vulnerabilities privately through GitHub's **Report a vulnerability** / private vulnerability reporting flow for this repository.

Do not place exploit details, credentials, tokens, private keys, or other secrets in a public issue.

Ordinary correctness bugs and language-design questions that do not require confidential disclosure may use the normal issue tracker.
