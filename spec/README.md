# Marak specification

This directory contains the normative Core specification.

Authority order:
1. `LANGUAGE_CHARTER.md`
2. `COMPUTATIONAL_CORE_REQUIREMENTS.md`
3. `surface/`
4. `semantics/`
5. conformance requirements
6. compiler implementation

The A13/B12 identifiers retained in filenames are historical decision IDs from the design process. They do not mean the documents are merely informal notes: the files indexed here are the current Core v0.1 integration-candidate baseline.

A future language edition may reorganize filenames without changing the meaning of an already published edition.
