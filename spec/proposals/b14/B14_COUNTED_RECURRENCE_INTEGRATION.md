# B14 Counted Recurrence Integration

Literal and dynamic A15 forms map to B13 `RepeatExactly(N,A)`.

N is Natural and is determined exactly once on entry. N=0 performs no body; N=1 performs once; finite
large N has no semantic ceiling. Count failure starts no iteration. Body error preserves completed
earlier iteration effects and prevents later iterations. Body divergence diverges the recurrence.

The dynamic `כמספר ...` form denotes the same Natural expression as its `המספר ...` counterpart,
with grammatical inflection only. It is not a new numeric domain.

Exactly one following AtomicAction is repeated. It cannot attach backward or absorb later
`ואחרי כן`. Composite repeated work must be a named act performance.

Repeated named-act performances may each produce their ordinary zero/one output because each is a
separate occurrence. Directly repeating Produce in one enclosing occurrence does not relax the
zero/one-output cardinality rule.
