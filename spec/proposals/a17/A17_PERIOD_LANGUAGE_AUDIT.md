## `מעלה` / `מעלות`

**Proposed phrases:** `מעלה אחת`, `שתי מעלות`, `COUNT מעלות`.

**Literal gloss:** one step/grade; two steps/grades; N steps/grades.

**Semantic intention:** one discrete coordinate distance from an origin.

**Primary evidence:** 2 Kings 20:9–11 repeatedly counts `עשר מעלות` and explicitly describes the shadow returning backward those steps; Isaiah 38:8 gives the parallel scale. These passages show a countable ordered scale with reversible movement, not merely the act of climbing.

**Morphology:** `מעלה` is feminine; plural `מעלות`. One therefore takes `אחת`, two takes `שתי`, and productive counts use the existing A15 feminine-count morphology.

**Syntax:** the counted noun precedes the directional PP: `N מעלות לפני/אחרי ...`. This is a controlled composition. The exact full A17 phrase is not claimed as a biblical quotation.

**Semantic risks:** unpointed `מעלה` can also represent verbal morphology in other contexts. A17 never recognizes bare `מעלה` as an Index literal. Counted phrases (`מעלה אחת`, `שתי מעלות`, `N מעלות`) and the fixed typed-head slots make the intended nominal reading structurally recoverable.

**Confidence:** HIGH for the noun/number scale; MEDIUM-HIGH for its controlled use as a general Index head.

## `מעלת היתד`

**Proposed phrase:** `מעלת היתד`.

**Literal gloss:** the step/grade of the peg/anchor.

**Semantic intention:** the distinguished origin (`ZeroIndex`) in the generic profile.

**Primary evidence:** `יתד` is an ordinary Biblical peg/stake; Isaiah 22:23 uses a peg fixed in a secure place, and Ezra 9:8 uses `יתד` metaphorically for a secured foothold/reference. The Megillah itself says `יום היסוד יתד הוא וממנו ימדדו הימים...`, which supplies the domain-specific motivation for choosing the peg metaphor.

**Morphology:** construct singular `מעלת` + definite singular `היתד`.

**Syntax:** standard construct-chain shape. The exact phrase `מעלת היתד` is a **controlled new composition**; no direct biblical occurrence of that phrase is claimed.

**Semantic risks:** a reader could initially imagine a physical stair associated with a peg. The larger closed family (`N מעלות לפני/אחרי מעלת היתד`) resolves the peg as the fixed reference grade. This is preferable to `יסוד`, which risks implying a first/lower bound, and to `אין`, which A15 deliberately confined.

**Confidence:** MEDIUM-HIGH.

## Direction words `לפני` / `אחרי` / `אחר`

These are already privileged in current Marak and ordinary Biblical relational vocabulary. The Megillah itself uses `לפני`/`אחרי` for the day relation and the existing A15/A16 year Index profile uses the same opposition. A17 therefore introduces no new directional lexeme.

Literal family:
- `... לפני מעלת היתד`
- `... אחרי מעלת היתד`

Strict order:
- `A לפני B`

Neighbor operations:
- `המעלה אשר אחר I`
- `המעלה אשר לפני I`

The neighbor forms are a controlled noun-head generalization of already accepted A16 year forms `מספר השנה אשר אחר/לפני I`.

## Feminine carrier agreement

Because `מעלה` is feminine, A17 does not copy masculine `יעמד/עומד/יצא` mechanically.

Proposed:
- `תעמד מעלה ...`
- `המעלה אשר עומדת ...`
- `המעלה אשר יצאה עתה ...`

Primary morphology controls:
- Psalm 33:11 has feminine subject `עצה` with `תעמד`.
- Psalm 111:3,10 has feminine `צדקה/תהלה` with `עומדת`.
- Ezekiel 7:10 attests feminine `יצאה`.

The exact programming phrases are controlled compositions, not biblical quotations.

**Agreement result:** PASS.

## Normalization audit

All selected forms survive the Charter's transformations:
- niqqud removal: selected canonical source is already unpointed;
- punctuation erasure: no punctuation delimits a field;
- Markdown erasure: no Markdown marker carries grammar;
- whitespace collapse: all boundaries use ordinary word separation;
- line-break removal: constructions remain the same normalized word sequences.

`מעלה`, `מעלות`, `מעלת`, and `המעלה` remain distinct after normalization; punctuation cannot turn one into another.

## Modern/calqued wording rejected

A17 rejects `אינדקס`, `אינט`, “signed”, unary-minus language, Date/Time terminology, angle-bracket type notation, and `אפס` as the generic origin spelling. None is needed to state the selected Biblical-Hebrew relation.
