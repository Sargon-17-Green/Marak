# B16 Backward Compatibility

B16 changes no existing semantic law.

- A15/A16 year profile remains unchanged.
- B13 still has one BidirectionalIndex domain.
- B15 static domain flow remains exact-domain based.
- Natural arithmetic and subtraction remain Natural-only.
- Program Input identity/binding lifecycle is unchanged.
- role association remains named and occurrence-local.
- output remains nonterminal with B12/B15 provenance.
- no Boolean Value appears.
- no source conversion or generic signed arithmetic is added.

The accepted A17 general profile is additive surface over the existing Index domain.

Source profiles are canonical within their own construction families; semantic canonicality is the
unique B13 Value, not a unique spelling. Source-preserving formatting preserves the parsed profile.
Value-only source synthesis requires an explicit target profile.
