Evidence is descriptive; it does not define B semantics by itself.

- REQUEST-007: original early discourse explicitly takes two days and names them calculation day / queried day; this motivates named external input association rather than positional transport.
- REQUEST-006: source repeatedly uses exact counted phrases including grinding eleven times, mixing twelve times, multiplying/taking by 149, 720, and other counts; the observable need is exact cardinality, not a loop index.
- REQUEST-004: source repeatedly compares values with strict and non-strict רב/ימעט relations when choosing candidates and bounds.
- REQUEST-002: year-number discourse explicitly walks from year one to zero and then one/two before zero, with a separate minus-sign rendering instruction.
- REQUEST-003: cutlet/month sections create books, books-of-books/permutations, traverse head/next positions, order books lexicographically, and select one.
- REQUEST-001: source declares fixed cutlet/month name inventories, treats multiword/phonetic labels as single names, assigns/chooses them, and includes cutlet/month names in the final day result.
- REQUEST-005: D2 identifies direct numeral spelling beyond the A13 1..9999 frozen grammar while B12 Natural semantics is already unbounded.

B13 deliberately uses this evidence to identify observations, while rejecting source-specific calendar concepts as language primitives.
