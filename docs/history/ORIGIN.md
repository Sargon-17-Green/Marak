# Origin of Marak

Marak did not begin as a planned programming-language project.

The project grew out of a Pastafarian calendar Megillah. In that work, the archaic Hebrew word **מרק** — “sauce” in the intended old usage — became the name of a function involved in determining the Pastafarian date.

The Megillah itself was written using deliberate archaisms. At one point the text was pushed toward almost-authentic ancient Hebrew. From there came a deliberately whimsical question: what if the Megillah were not merely prose describing an algorithm, but actual compilable source code in a new programming language?

That whim became Marak.

The origin is intentionally not hidden or retroactively made more solemn. Marak is an esoteric language whose design is nevertheless treated rigorously: its surface language, semantics, compiler, conformance tests and the Megillah must agree without relying on hidden programming conventions.
