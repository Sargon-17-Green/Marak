# C Semantic Core after Anti-Imitation Audit

Status: reconciled with A13/B12.

The post-audit Core is not modeled as translated conventional language syntax. It consists of exact Natural values, named state-bearing places/current facts, proposition judgments, explicit source relations for sequence/conditional/recurrence, described Acts and performance occurrences, named occurrence-local roles, optional numeric occurrence products and normal exhaustion.

A13/B12 close the formerly open M3 program/visibility/whitespace/completion/subtraction issues. C now has canonical HAST and IR for these distinctions while keeping implementation stacks/registers/loops/host functions out of the normative model.
